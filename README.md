# Telegram-бот IngriaFarm

Бот раз в пять минут проверяет [каталог IngriaFarm](https://ingriafarm.com/ru). При переходе с 0 на положительный остаток он присылает название позиции, точное количество и ссылку на карточку.

Отслеживаются четыре позиции со скриншота.

- КИНГ USA — аккаунтам 12–24+ месяцев, фарм 10–14 сессий
- КИНГ UA — топ фарм 12–24+ месяцев
- КИНГ USA — топ фарм 12–24+ месяцев
- Сетап KING FB USA + 8–9 USA личек

## Первый запуск

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot` и завершите создание бота. [Инструкция Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token)
2. В папке с `bot.py` создайте файл `.telegram-token` с токеном на одной строке. Токен можно также передать через переменную окружения `TELEGRAM_BOT_TOKEN` или через `--token-file /путь/к/файлу`.
3. В терминале из этой папки выполните команды ниже. Нужен Python 3.9 или новее.

   ```bash
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   .venv/bin/python bot.py
   ```

4. Откройте бота по ссылке в терминале и отправьте ему любое сообщение в личном чате. Бот ответит «Уведомления включены». Для отписки отправьте `/stop`, а для повторной подписки — `/start`.

## Работа бота

При первом запуске бот запоминает начальные остатки. Изменение с одного положительного количества на другое проходит без уведомления. Следующее уведомление по той же позиции придёт после того, как бот увидит нулевой остаток и новое поступление. Бот сохраняет подписки и последние остатки в `data/stock.sqlite3` или в файле, указанном через `--db`.

Для круглосуточных проверок держите один экземпляр бота запущенным на компьютере или сервере, с которого открываются IngriaFarm и Telegram Bot API. На локальном компьютере проверки приостанавливаются, когда он спит или выключен.

Разбор четырёх карточек проверен на живом каталоге. Переход с нуля на положительное количество проверен на сохранённой разметке этих карточек с выставленными тестовыми остатками.
